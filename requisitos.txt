Atue como Desenvolvedor Web Senior e Especialista em Design de Áudio Interativo, WebRTC e Acessibilidade. Crie uma aplicação web completa (HTML, CSS e JavaScript em arquivo único ou modular via CDN com Tone.js, PeerJS e QRCode.js) chamada "A Sinfonia da Terra: Earth Jukebox Multissensorial".

O objetivo é converter dados e imagens terrestres da NASA (e de pastas locais enviadas pelo usuário) em uma paisagem sonora instrumental imersiva, acessível e personalizável.

Requisitos Obrigatórios do Projeto:

1. ARQUITETURA DE CÓDIGO E CONSTANTES DE MAPEAMENTO (DEVS-FRIENDLY):
- Defina no topo do código um objeto global de configuração com Constantes de Mapeamento claras para facilitar alterações futuras pelo desenvolvedor:
  const MAPPING_CONFIG = {
    TEMPERATURE: 'CELLO',       // Águas frias a quentes
    HUMIDITY: 'FLUTE',          // Nuvens e Umidade Atmosférica
    VEGETATION_DENSITY: 'MARIMBA', // Altura do Dossel (GEDI)
    OCEAN_CURRENTS: 'HARP',     // Velocidade e Fluxo de Água
    ALTITUDE_ELEVATION: 'PIANO' // Relevo
  };
- Inclua um dicionário completo de amostras e sintetizadores (SAMPLE_SET) contendo TODOS os instrumentos disponíveis para testes rápidos no código:
  ['CELLO', 'DOUBLE_BASS', 'GRAND_PIANO', 'MARIMBA', 'FLUTE', 'HARP', 'VIOLIN', 'CLARINET', 'SYNTH_PAD', 'STEEL_DRUM'].

2. LEGENDA INTERATIVA AMPLIADA COM PRÉ-ESCUTA NO HOVER:
- Exiba uma Tela/Modal de Legenda Ampliada (interface de grande dimensão e alto contraste) antes de carregar a exploração gráfica.
- A legenda deve explicar o significado de cada cor/dado, qual constante está associada e qual instrumento está tocando.
- INTERAÇÃO NO HOVER: Ao passar o mouse sobre cada card da legenda (evento `mouseenter`), o áudio do instrumento correspondente deve tocar imediatamente em pré-visualização (sem necessidade de clicar em botões).

3. SONIFICAÇÃO INSTRUMENTAL E AUDIO DUCKING (VOZ SOBRESSAI AO SOM):
- Sonificação Contínua em tempo real à medida que o cursor percorre os pixels do Canvas.
- As frequências devem ser quantizadas na Escala Pentatônica Maior para manter harmonia agradável.
- REQUISITO DE AUDIO DUCKING (Voz Prioritária):
  * Quando a síntese de voz (Web Speech API / ARIA Live) estiver ativa para ler dados de acessibilidade para o usuário, diminua automaticamente o volume geral dos instrumentos (ex: redução de -12dB a -18dB ou 20% do volume original).
  * Assim que a voz terminar de falar, restaure suavemente (via rampTo) o volume dos instrumentos ao nível normal.

4. SINCRONIZAÇÃO HÁPTICA PROPORCIONAL COM SMARTPHONE (WEB RPTC / PEERJS):
- Painel para gerar QR Code de conexão P2P via PeerJS.
- O celular conectado funcionará como receptor hápico em tempo real.
- VIBRAÇÃO PROPORCIONAL À COR:
  * A frequência e a intensidade da vibração enviada ao smartphone (`navigator.vibrate`) devem ser estritamente proporcionais ao valor numérico/matiz da cor do pixel sob o cursor (ex: tons de vermelho/temperaturas altas = vibrações curtas e de alta frequência; tons de azul/frio = vibrações longas e pulsantes de baixa frequência).

5. GALERIA LOCAL E ACESSIBILIDADE INTEGRADA:
- Suporte para carregar pasta local de imagens do computador (`<input type="file" webkitdirectory>`) mantendo miniaturas clicáveis, além dos datasets padrão da NASA (ECCO2, GEDI, Atmospheric River).
- Controle sensorial (Low-Sensory Mode para limitar volumes e altas frequências).
- Navegação 100% via Teclado com cursor focal em grade e filtros para daltonismo.
