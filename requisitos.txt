Atue como Desenvolvedor Web Senior e Especialista em Design de Áudio Interativo, WebRTC e Acessibilidade. Crie um projeto web completo (HTML, CSS e JavaScript) em arquivo único (ou modular utilizando Tone.js, PeerJS e QRCode.js via CDN) chamado "A Sinfonia da Terra: Earth Jukebox Multissensorial".

O objetivo da aplicação é traduzir imagens de dados terrestres (da NASA ou enviadas pelo próprio usuário) em uma experiência de sonificação instrumental, altamente inclusiva, relaxante e interativa em tempo real.

Requisitos Obrigatórios do Projeto:

1. CARREGAMENTO DE PASTA LOCAL DE IMAGENS (GALERIA):
- Implemente um leitor de pasta local (utilizando `<input type="file" webkitdirectory directory multiple>` ou seletor múltiplo de arquivos de imagem JPG, PNG e WebP).
- Crie uma Galeria de Escolha onde todas as imagens carregadas da pasta do computador são exibidas em miniaturas clicáveis com o nome do arquivo.
- Mantenha 2 imagens de dados da NASA pré-carregadas por padrão (Temperatura dos Oceanos ECCO2 e Altura das Florestas GEDI) para uso imediato caso o usuário não selecione uma pasta local.

2. TELA DE LEGENDA AUDITIVA E SENSORIAL (ONBOARDING PRÉVIO):
- Antes de iniciar a navegação na imagem selecionada, apresente obrigatoriamente uma Tela de Legenda Explicativa (Modal / Card de Preparação Sensorial).
- Esta tela deve mostrar qual característica ambiental/cor cada instrumento representa e conter botões de teste áudio para o usuário ouvir e aprender cada som individualmente antes de explorar:
  * Violoncelo / Contrabasso (Grave): Representa Águas Frias / Baixas Temperaturas / Regiões Polares.
  * Piano de Cauda / Marimba (Médio): Representa Temperaturas Amenas e Vegetação Moderada.
  * Flauta / Sopros de Madeira (Agudo): Representa Alta Umidade, Nuvens ou Dossel Florestal Elevado.
  * Harpa / Percussão Leve (Arpejos/Rhythm): Representa a Intensidade de Correntes Marítimas ou Ventos Fortes.
- Inclua o botão "Iniciar Experiência Multissensorial" ao final da legenda para carregar o canvas interativo.

3. SONIFICAÇÃO INSTRUMENTAL CONTÍNUA EM TEMPO REAL (HOVER):
- O som NÃO deve ser estático por imagem. À medida que o mouse transita pelos pixels da imagem, os instrumentos e suas notas se alteram continuamente e em tempo real.
- Polifonia por Camadas Instrumentais (Tone.js / Web Audio API):
  * Eixo X (Panning Estéreo): Posição horizontal do mouse direciona o som suavemente entre os canais Esquerdo e Direito.
  * Matiz da Cor / Temperatura: Mapeie a cor sob o cursor para a nota do instrumento principal (quantizada na Escala Pentatônica Maior de Dó ou Sol para garantir uma sonoridade extremamente agradável e musical).
  * Brilho / Umidade / Densidade: Ative camadas secundárias (ex: arpejos de harpa ou soprano de flauta) conforme a intensidade dos pixels aumenta.
- Suavização de Áudio (Interpolção/Glide): Aplique rampas suaves de transição (rampTo) para eliminar estalos, ruídos secos ou mudanças bruscas de volume.

4. SINCRONIZAÇÃO HÁPTICA COM O SMARTPHONE (VIBRAÇÃO VIA QR CODE):
- Na interface principal do computador, inclua um painel "Conectar Smartphone (Vibração Tátil)".
- Ao clicar, gere um QR Code único utilizando PeerJS (conexão WebRTC Peer-to-Peer nativa sem necessidade de servidor backend dedicado).
- Ao escanear o QR Code com a câmera do celular, o smartphone abre uma página receptora leve.
- Conforme o usuário move o mouse sobre a imagem no computador, o computador envia pacotes de dados via WebRTC em tempo real para o celular, acionando a Vibration API (`navigator.vibrate`) com padrões e frequências de vibração variáveis conforme o mouse cruza zonas de transição térmica ou de alta densidade.

5. ACESSIBILIDADE E CONFORTO SENSORIAL:
- Modo de Baixa Sensibilidade (Low-Sensory Mode): Botão para ativar limitador de volume e suavização extrema de frequências para usuários neurodivergentes ou com hipersensibilidade auditiva.
- Navegação Completa por Teclado: Teclas direcionais movimentam um cursor focal virtual pela imagem.
- Síntese de Voz / ARIA Live: Anúncia verbalmente para leitores de tela os dados sob o cursor (ex: "Zona Atlântica: Violoncelo e Piano - Temperatura 22°C").
- Layout responsivo, elegante e limpo com suporte a modos de alto contraste e filtros de cor para daltonismo.
